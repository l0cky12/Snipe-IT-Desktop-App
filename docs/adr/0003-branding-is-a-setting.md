# Branding is a setting; the installer stays as built

Another organisation installing this app wants its own name, icon and colours, in the window and on exported Reports. We made Branding a tab in Settings: the organisation name, a square PNG icon, a primary and an accent colour as hex, and a Report footer line. They're global to the install (one Snipe-IT server per install) and typed in here, not read from Snipe-IT: its API exposes no site name, logo or colours.

What follows the setting: the sidebar brand, the window title, the window and taskbar icon, the tray icon, tooltip and menu, the test email, and the header band and footer of exported HTML and PDF Reports (`reportHtml`, one template for both: the PDF is Electron's print-to-PDF of it, landscape Letter, with the footer line and page numbers on every page). What doesn't: the installer's product name, the app ID (`net.nomma.snipe-it-desktop`), the Linux autostart entry's name, the launcher's icon, and About. Those are baked in at install time; changing the app ID would move the settings folder and log out every install, and a launcher icon per organisation means a build per organisation, which is a different product. Settings says so under the icon.

Colours are two slots, not a palette. The stylesheet already derives everything brand-coloured from `--navy` and `--gold`, so the setting overrides those two custom properties on the page (`applyColors`) and the page's neutral surfaces, which make the light and dark themes work, stay put. Text on each colour is computed: on the accent, the primary colour when it contrasts 4.5:1 (NOMMA's navy on gold), otherwise black or white by luminance. Until saved, the defaults are NOMMA's navy and gold, so a fresh install looks as it always has, not unbranded.

The icon is a PNG only: Electron's native image loader takes no SVG, and every organisation has a PNG of its logo. It's copied beside `settings.json` as `branding-icon.png` (an original on a USB stick or network share would go missing) and handed to the window as a data: URL. With no icon, the sidebar tile shows the first letter of the name.
